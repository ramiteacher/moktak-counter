# 목탁 수행 카운터

목탁 소리를 일정한 박자로 들으며 108번, 1000번, 3000번, 10000번 수행을 진행할 수 있는 단일 HTML 웹사이트입니다.

## 기능

- 목표 횟수 선택: 108 / 1000 / 3000 / 10000
- 시작 전 준비 루틴
  - 카운트다운: 3초 / 5초 / 10초
  - 인사/예불 시작 느낌의 목탁 3타
  - 반배 목탁 3번
  - 준비 루틴 목탁은 수행 카운트에 포함하지 않음
- 리듬 선택
  - 예불 정박: 예불·염불 수행처럼 차분하고 고르게 이어지는 기본 박자
  - 독경 유동박: 경문을 따라가는 느낌의 미세한 강약/간격 변화 박자
  - 삼타 신호박: 딱·딱·딱 세 번 치고 길게 쉬는 의식 전환형 박자
- 속도 조절: 40~120 BPM 및 느림/보통/빠름
- 목탁 소리 반복 재생 및 카운트
- 진행률 바, 남은 횟수, 완료 메시지
- 모바일 반응형 UI
