# 목탁 수행 카운터

목탁 소리를 일정한 박자로 들으며 108번, 1000번, 3000번, 10000번 수행을 진행할 수 있는 단일 HTML 웹사이트입니다.

## 기능

- 목표 횟수 선택: 108 / 1000 / 3000 / 10000
- 리듬 선택: 정박 / 엇박 / 신호용 박자
- 속도 조절: 40~120 BPM 및 느림/보통/빠름
- 목탁 소리 반복 재생 및 카운트
- 진행률 바, 남은 횟수, 완료 메시지
- 모바일 반응형 UI

## 파일

- `index.html` — 전체 웹앱
- `moktak.png` — 목탁 이미지
- `moktak.mp3` — 목탁 소리
- `temple-bg.jpg` — 배경 이미지
